# 우리집 산수 (v2)

만 4세 ~ 초등 2학년 · 태블릿 가로 화면 · 가정용 웹앱.
`2026-09-24 우리집 산수앱 기획안 v2`를 그대로 구현했습니다.

- 빌드 도구 없음. HTML + CSS + 바닐라 JS(ES 모듈)만 씁니다.
- 모든 기록은 **이 기기 안에만** 저장됩니다 (진도: localStorage, 사진 스티커: IndexedDB). 서버로 올리지 않습니다.
- 지시는 모두 한국어 음성(브라우저 TTS)으로 나오고, 만 4세 화면에는 글자를 띄우지 않습니다.

## 실행

```bash
npm start          # http://localhost:8080 (npx http-server)
npm test           # 규칙·커리큘럼 테스트 (Node 20+)
```

ES 모듈이라 `index.html`을 파일로 직접 열면 동작하지 않습니다. 정적 서버로 열어 주세요.

### GitHub Pages로 태블릿에서 쓰기

1. 저장소 **Settings › Pages › Source: Deploy from a branch**, 브랜치 `main`, 폴더 `/ (root)`
2. 태블릿에서 `https://<아이디>.github.io/math/` 열기 → 브라우저 메뉴 **홈 화면에 추가**
3. 가이드 접근(iPad)이나 앱 고정(안드로이드)을 켜 두면 아이가 앱 밖으로 나가지 않습니다.

## 구조

```
index.html            화면 틀
css/app.css           스타일 (연령별 터치 크기는 CSS 변수)
js/config.js          기획안 수치 전부 (연령별 상한·간격·쉼터 시간 등)
js/curriculum.js      70단원 + 문제 생성기 + 진단 문항 + 시작표
js/engine.js          착석·단원 선택·통과·자동 보정·스티커·쉼터·오답 사다리
js/stickers.js        가변비율 추첨, 이월, 디자인, 칭찬 문구
js/diagnostic.js      "동물 친구 인사" 적응형 진단
js/art.js             그림 (SVG/HTML 문자열)
js/main.js            아이 화면
js/parent.js          부모 화면 (3중 잠금)
js/store.js, audio.js 저장 / 음성·효과음
tests/                node:test
```

`engine.js`·`curriculum.js`·`stickers.js`·`diagnostic.js`는 DOM을 쓰지 않아서 Node에서 그대로 테스트됩니다.

### 기획안과 다르게 정한 것

- **C5 내가 만드는 규칙**: 기획안은 "빈칸 4개"지만, 4칸으로는 ABC 반복을 만들 수 없어 **6칸**으로 했습니다. 2개 또는 3개가 되풀이되고 두 가지 이상을 썼으면 규칙 성립.
- **B9 자 눈금 읽기**: 시작표(만 8세에 B9 열림)와 선행 조건(cm 읽기는 L3 이후)이 부딪혀 **선행 조건을 우선**했습니다.
- **B10 몇 m 몇 cm**: 135 cm처럼 세 자리 수가 나와서 L6-2(세 자리 수) 통과를 선행 조건으로 추가했습니다.
- **4세 "혼자 진행한 구간"**: 앱이 어른의 동석을 직접 알 수 없어서, 쉼터에 있는 "어른이 함께 있어요" 버튼으로 확인하고 1차 쉼터 시간 이후 확인이 없던 문제를 "혼자 진행(추정)"으로 셉니다.
- **부모 알림**: 부모 기기가 따로 없어서, 알림은 부모 화면의 "알림" 탭에 쌓입니다. 아이 화면에는 띄우지 않습니다.
