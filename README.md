# 우리집 산수

만 4세 ~ 초등 2학년 · 태블릿 가로 화면 · 가정용 산수 놀이 웹앱

- **이름·프로필 없이** 첫 화면에서 난이도만 고르면 바로 시작합니다.
- 고른 난이도의 문제**만** 나옵니다. (만 4세 = 세기만, 초2 = 구구단만)
- **7문제마다 스티커 1장.** 위쪽 발자국 7개가 다 차면 스티커를 받고, "스티커 모음"에 모입니다. 아직 없는 스티커가 먼저 나와서 모음이 점점 채워집니다.
- 더하기는 동물이 **뛰어 들어오고**, 빼기는 동물이 **손 흔들고 떠나고**, 곱하기는 동물이 **몇 마리씩 묶음으로** 나타납니다. 두 자리 수는 수 모형(십 막대·낱개)이 들어오고, 낱개 10개가 십 막대로 묶이거나 막대가 풀립니다.
- 빌드 도구 없음(HTML + CSS + JS 모듈). 기록은 이 기기에만 저장됩니다(서버 업로드 없음).

## 난이도

| 카드 | 나오는 문제 | 모션 |
|---|---|---|
| 🐥 만 4세 · 하나 둘 셋 세기 | 1~5 세기 (눌러서 세기) | 누른 것에 ✓ 표시 |
| 🐰 만 5세 · 열까지 세기 | 10까지 세기, 수의 순서 | 누른 것에 ✓ 표시 |
| 🐶 만 6세 · 10까지 더하기·빼기 | 합 10 이하, 빼기 | 동물 |
| 🐻 초1 · 20까지 더하기·빼기 | 10 만들어 더하기, 십몇−몇 | 동물 |
| 🦊 초1~2 · 두 자리 더하기·빼기 | 받아올림·받아내림 | 수 모형 |
| 🐼 초2 · 구구단 | 2·5단 → 2~5단 → 2~9단 | 동물 묶음 |

난이도 안에서는 **처음엔 쉽게** 시작합니다. 한 번에 맞히기를 5번 연속 하면 한 단계 어려워지고, 2문제 연속 틀리면 한 단계 쉬워집니다(쉬움·보통·어려움).

틀렸을 때: 고른 보기가 연회색으로 물러나고(빨간색·흔들림 없음), 3초 뒤 💡 힌트 → 두 번째로 틀리면 모션을 다시 보여 주고 → 세 번째부터 보기를 2개로 줄입니다. 틀려도 끝까지 풀면 스티커 칸은 채워집니다.

## 보호자 화면

오른쪽 아래 ⚙️를 **2초 길게 누른 뒤** 곱셈 문제(두 자리 × 한 자리)를 풀면 열립니다.
- 난이도별 푼 문제 수와 현재 단계, 받은 스티커 수
- **내 사진 스티커**: 가족 사진을 원형으로 잘라 넣으면 스티커로 나옵니다(최대 20장)
- 초기화, 기기 설정 안내(가이드 접근·앱 고정)

## 실행

```bash
npm start   # http://localhost:8080
npm test    # Node 20+
```

`index.html`을 파일로 바로 열면 동작하지 않습니다(ES 모듈). 정적 서버나 GitHub Pages로 열어 주세요.

**GitHub Pages**: Settings › Pages › Source `main` / `(root)` → 태블릿에서 `https://jaehyun870704-dotcom.github.io/math/` 열고 **홈 화면에 추가**.
